## Why

The current folder ZIP is a viewable tile delivery, but extracting it loses the editable Map Studio project state. Users need that extracted folder to reopen as a working project with its map layer, saved control points, user-created icon points, and map settings intact.

## What Changes

- Add a versioned `mapstudio.json` project document to the existing exported folder layout while retaining `metadata.json`, the four HTML viewers, and XYZ PNG tiles.
- Include the original raster source as a managed folder asset when one is available, so raster editing and control-point image coordinates can be restored.
- Add bounded directory and ZIP import APIs that restore the same project contents in one database transaction.
- Add Map Studio UI actions for selecting either an extracted export directory or its unmodified `.zip` and opening the restored project directly.
- **BREAKING** Remove raw raster, vector, MBTiles, style JSON, and `.mtmap` inputs from the frontend and unregister their legacy upload/import routes.
- Treat imported folder tiles as a normal raster map layer without requiring regeneration or an MBTiles container.

### New Capabilities

- `folder-project-round-trip`: Exported Map Studio folders preserve editable project state and can be selected after extraction to restore the project and raster tile layer.
